## Round 1 — 6건

- [논리] metrics.py:94 — 소르티노 하방편차를 `_stdev([min(0,r) …])` 로 계산.
  표본 stdev 는 (음수) 평균으로 디민 + ddof=1 → 하방편차 과소평가 → 소르티노 과대.
  → 목표수익률 0 기준 `sqrt(sum(min(0,r)^2)/n)` 로 교체.
- [계약] metrics.py — `performance_stats` 3개 반환 분기의 키 집합 불일치.
  `_EMPTY` / `<20일` 분기에 `years` 누락, full 분기에만 존재 → 소비자 `s["years"]` KeyError 위험.
  → 두 분기에 `"years": None` 추가 (전 분기 8키 통일).
- [최적화] metrics.py:103 — full 분기에서 `_max_drawdown(rets)` 재호출 (line 76 `mdd` 이미 계산).
  → `round(mdd, 4)` 재사용.
- [논리] paper.py:22 `nav_usd` — 보유 티커가 `prices` 에 없으면 조용히 equity 에서 제외 →
  일일 평가 시 NAV 유령 급락 후 회복 (equity curve·모든 지표 오염). Gate B 핵심 아티팩트.
  → `prices.get(t, p.avg_cost_usd)` 폴백 + docstring 에 "호출자는 보유 티커 전부 공급" 전제 명시
  + `ponytail:` 주석. (근본 해결은 3a-8/3a-10 이 완전한 가격 딕셔너리 공급.)
- [불변식/오타] schemas.py — `Order.side` / `Fill.side` 가 맨 `str` (`# buy | sell` 주석만).
  오타(`"Buy"`)가 `execute` 의 `o.side != side` 필터에서 조용히 드롭 (skipped 에도 안 들어감).
  → `Literal["buy", "sell"]` (Pydantic 경계에서 거부).
- [테스트] test_paper.py:42 — `pf.cash_usd >= 0.0` 을 현금 전액 소진 부동소수 잔차(~-1e-14)에
  정확 비교. → `>= -1e-6`.
