## Round 1

- **[논리]** `regime.py` `_axis_vix` — `backwardation = m.vix >= v3`. VIX == VIX3M(평탄 기간구조)을 백워데이션으로 오판 → 과도하게 -2. → `> v3` (정확히 같으면 중립).
- **[코드]** `regime.py` `_sub_score` — `thresholds` 리스트를 ascending/descending 분기에서 중복 정의. → 1회 정의 + 분기는 비교 연산자만.
- **[설계/robustness]** present 축이 2개(FRED 키 없을 때)여도 `sum * 6/2` 정규화가 +6까지 증폭 → 얇은 데이터로 BULL 확정. phase-2 명세엔 없으나 실전 위험. → `min_axes_for_label: 4` 추가. `n_present < 4` → `low_confidence=True`, 라벨을 NEUTRAL 로 강등 (CRISIS 오버라이드는 raw 값이라 영향 없음). `total_score`·`score_smooth` 는 계속 계산(연속성). 감시견은 low_confidence 날을 history 에 안 쌓음(3a-4 반영).
