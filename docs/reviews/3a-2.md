## Round 1

- **[명세대조]** `market_data.py` + `docs/TOOLS.md §1` — `lookback_days` 파라미터가 코드에서 미사용, 기본값 불일치(문서 400 / 코드 1300). → 파라미터 제거, 문서 "항상 5년 조회" 로 통일.
- **[논리/단위]** `macro_data.py` `_Fred.fed_trend()` — FRED `DFF` 는 7일 일간(주말 포함)이므로 126 관측치 ≈ 4.2개월. 6개월 의도와 불일치. → 180 관측치로 수정.
- **[논리]** `fundamentals.py` `_get()` — FMP 에러 응답은 dict(`{"Error Message": ...}`), `dict[0]` → TypeError. → `_get` 이 항상 `list[dict]` 반환하도록 정규화(`isinstance(data, list)`).
- **[코드]** `indicators.py` `beta()` — 이름 같은 두 Series 를 `pd.concat` → 중복 컬럼명. `.iloc` 로 동작하나 취약. → concat 전 `.rename("asset"/"market")`.
- **[코드]** `news.py` `_scrape_macro()` — 2개 피드 병합 시 중복 헤드라인 미제거. → `_dedup()` (제목 앞 60자) 추가.
