  `_size_category` 가 `cat.upper()`, `cw` 집계도 `c.upper()` 비교 → **소문자로 통일**
  (portfolio_math + schemas 주석 + 테스트).

  `market_breadth` dict 값이 잘못된 타입이면 조용히 regime 으로 전파. → `_as_float()` 로
  명시적 `float | None` 강제.
- [일관성] `_build_orders` 이탈종목 매도 `Order(category=pos.category)` 대소문자 미정규.
  → `(pos.category or "").lower() or None`.
- [명세/가시성] 사이징 예산으로 `plan.post_action_weights` 사용 → 초기/대전환 시
  `max_change_per_rebal`(카테고리 10%p/회) 때문에 목표까지 여러 주 램프업. 리포트에서
